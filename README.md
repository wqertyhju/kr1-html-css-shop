# Учебный интернет-магазин

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

## Описание проекта

Многостраничный сайт учебного интернет-магазина, разработанный на чистом HTML и CSS в рамках дисциплины «Фронтенд и бэкенд разработка». Проект включает семантическую разметку, БЭМ-именование классов, CSS-переменные, Flexbox/Grid-раскладки, адаптивную вёрстку и базовую JS-логику для модального окна заявки.

## Ссылка на опубликованный проект

GitHub Pages: https://wqertyhju.github.io/kr1-html-css-shop/

## Структура проекта

- `index.html` – главная страница (hero, преимущества, популярные товары);
- `catalog.html` – каталог товаров с фильтрами;
- `product.html` – страница товара с таблицей характеристик;
- `order.html` – страница оформления заявки;
- `contacts.html` – контактная информация;
- `css/style.css` – файл стилей (переменные, БЭМ, Flex/Grid);
- `js/main.js` – логика модального окна и обработки формы;
- `images/` – папка для изображений;
- `README.md` – описание проекта.

## Используемые технологии

- HTML5 (семантическая разметка);
- CSS3 (переменные, Flexbox, Grid, состояния `:hover`/`:focus-visible`);
- БЭМ-методология именования классов;
- JavaScript (ES6) — модальное окно и валидация формы;
- Git и GitHub;
- GitHub Pages (публикация).

## Реализованные элементы

- единая навигация на всех страницах;
- якорные ссылки (`index.html#advantages`, `#popular`, `#contacts`);
- хлебные крошки на внутренних страницах;
- карточки товаров с БЭМ-классами;
- таблица характеристик на странице товара;
- форма заявки с HTML-валидацией и JS-обработкой;
- модальное окно `<dialog>` для быстрой заявки;
- CSS-переменные (`:root`);
- состояния `:hover`, `:focus-visible`, `:disabled`;
- адаптивная вёрстка (медиазапросы, `scroll-behavior: smooth`, `:target`);
- позиционирование (sticky-шапка, `z-index`).
